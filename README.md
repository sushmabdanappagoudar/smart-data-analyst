# 📊 Smart Data Analyst

An AI-powered automated data analysis platform built with Python and Streamlit.

## 🚀 Features

- Upload CSV datasets
- Data cleaning
- Exploratory Data Analysis (EDA)
- Data visualization
- Machine Learning
- AI-generated insights

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Plotly
- Scikit-learn
